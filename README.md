# QuickNotes System Design & Implementation

QuickNotes is an end-to-end notes management application designed to scale up to 1 million users. This repository contains both the frontend REST API client interacting with a target service and complete backend system architecture specifications.

## Repository Layout
- `index.html` - Primary HTML interface.
- `style.css` - User interface styling.
- `api.js` - Asynchronous JavaScript API client.
- `docs/api-design.md` - RESTful API specifications and endpoints documentation.
- `docs/data-model.md` - Relational database schema, DDL statements, queries, and indexes.
- `docs/architecture.md` - Scalability specifications, capacity calculations, and system architecture diagram.
